# Ten Points in Circles

Interactive canvas to explore the puzzle of placing points and unit circles.

Inspired by 3Blue1Brown's explanation: https://www.youtube.com/shorts/QLu_ZsRc_G0

## Features

- Add/remove/select/multi-select points and unit circles
- Move selected items by mouse drag
- Move selected items by keyboard arrow keys in 1px increments
- Points outside every circle are yellow
- Circles that touch another circle are red
- Displays the total number of points
